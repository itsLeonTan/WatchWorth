# ⌚ WatchWorth

**WatchWorth** is a web-based game where you guess the final sale price of luxury watches sold at Sotheby's auctions.

This project was built primarily to practice web development while learning how to work with JSON data. Instead of relying on an API, the game uses a curated dataset of historical Sotheby's watch auction results.

## Scoring

Your score is determined by the accuracy of each guess:

* 🎯 **Exact match:** 1,000 points
* 📈 The closer your guess is to the actual sale price, the more points you earn.

Try to get the highest total score across all five rounds!

## Data

All watch information and historical sale prices were sourced from **Sotheby's** auction results.

This project is intended for educational and portfolio purposes and is not affiliated with or endorsed by Sotheby's.

## Why I Built This

The goals of this project were to:

* Practice modern web development with HTML, CSS, and JavaScript.
* Learn how to structure, store, and consume JSON data.
* Build a complete browser-based game from scratch.
* Gain experience creating an engaging, interactive frontend project.
